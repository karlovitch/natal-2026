# Natal 2026 — Presentes da Família

Gestor de presentes de Natal com dados iniciais, imagens, pagamentos, estados de encomendas, embrulhos e relatórios.

Site: https://karlovitch.github.io/natal-2026/

**Aviso:** repositório público, com os dados iniciais dos presentes. As alterações no navegador são guardadas localmente; não existe sincronização automática entre dispositivos.

A aplicação Android é compilada como APK de depuração no GitHub Actions.
